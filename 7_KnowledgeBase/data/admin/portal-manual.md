# 업무포털 사용 매뉴얼 예시 데이터

본 문서는 교육용으로 작성된 **가상의 자료**입니다. 실제 기관의 시스템이 아니며 실무에 적용할 수 없습니다.

기관명은 가상의 **넥스트클라우드대학교**(약칭 넥클)이며, 업무포털은 `portal.nxtcloud.ac.kr`로 표기합니다.

# 로그인 및 계정 관리

### 최초 접속 방법

넥클 업무포털은 `portal.nxtcloud.ac.kr`로 접속합니다. 최초 접속 시에는 사번과 초기 비밀번호(생년월일 6자리 + 임시코드)로 로그인한 뒤, `업무포털 → 계정관리 → 초기 비밀번호 변경` 화면으로 자동 이동합니다. 이 화면에서 새 비밀번호와 개인 이메일, 휴대전화번호를 입력하지 않으면 다음 화면으로 넘어가지 않으므로 유의하십시오.

### 비밀번호 규칙과 변경 주기

비밀번호는 영문·숫자·특수문자를 조합해 10자 이상으로 설정해야 하며, 90일마다 변경을 요구하는 팝업이 뜹니다. 변경 화면은 `업무포털 → 계정관리 → 비밀번호 변경`이며, `[현재 비밀번호 확인]` 버튼을 눌러야 새 비밀번호 입력란이 활성화됩니다. 만료 7일 전부터는 로그인 시마다 안내 배너가 상단에 표시됩니다.

### 계정 잠금 해제 절차

비밀번호를 5회 연속 잘못 입력하면 계정이 잠깁니다. 본인이 직접 해제하려면 로그인 화면의 `[비밀번호 찾기]` 링크에서 등록된 개인 이메일로 인증코드를 받아 처리하십시오. 인증코드 요청 후 화면을 벗어나면 코드가 만료되므로, 새 창을 열지 말고 같은 화면에서 대기해야 합니다. 이메일 인증이 되지 않는 경우에는 헬프데스크(`업무포털 → 우측 하단 헬프데스크 아이콘`)로 신분증 사본을 첨부해 요청하십시오.

### 인증서와 2단계 인증

교외에서 접속할 때는 개인용 공동인증서 또는 모바일 OTP 앱을 통한 2단계 인증이 추가로 요구됩니다. `업무포털 → 계정관리 → 보안설정` 탭에서 인증서를 등록하며, `[인증서 등록]` 버튼을 누른 뒤 안내되는 순서대로 파일을 첨부하면 됩니다. 세션은 무입력 상태로 30분이 지나면 자동 종료되며, 이 경우 하던 작업 중 저장하지 않은 입력값은 사라집니다.

# 메인 화면 구성

### 상단 메뉴 구조

로그인 후 첫 화면은 대시보드이며, 상단에는 `복무관리`, `전자결재`, `예산·구매`, `시설예약`, `인사·급여` 등 대분류 메뉴가 가로로 배치됩니다. 각 대분류에 마우스를 올리면 하위 메뉴 목록이 펼쳐지며, 원하는 화면명을 클릭해 이동합니다. 경로 표기는 이 문서 전체에서 `업무포털 → 대분류 → 화면명` 형식을 따릅니다.

### 즐겨찾기 등록

자주 쓰는 화면은 상단 메뉴 우측의 `[즐겨찾기 추가]` 아이콘(별 모양)을 눌러 등록할 수 있습니다. 등록된 화면은 대시보드 좌측 `즐겨찾기` 패널에 표시되며, 순서는 드래그로 재배열 가능합니다. 즐겨찾기는 최대 10개까지 등록되며, 초과 시 가장 오래된 항목이 자동으로 제거됩니다.

### 알림함 확인

대시보드 우측 상단의 종 모양 아이콘을 누르면 결재 대기, 반려, 공지사항 알림이 목록으로 표시됩니다. 항목을 클릭하면 해당 화면으로 바로 이동합니다. 알림 목록은 최근 30일치만 보관되며, 그 이전 알림은 `업무포털 → 알림함 → 전체보기`에서 별도 조회해야 합니다.

### 개인 설정 변경

`업무포털 → 개인설정`에서는 부서 대표번호, 좌석 위치, 결재 위임 대상 등을 등록합니다. 부재중 설정을 켜면 이후 기안 문서의 결재선에서 본인이 자동으로 대결자로 대체됩니다.

# 복무관리 메뉴

### 출퇴근 등록

출근 시각은 `업무포털 → 복무관리 → 출퇴근 등록` 화면에서 사무실 내부망 접속 시 자동 기록되며, 원격지에서 근무하는 경우에는 `[수동등록]` 버튼을 눌러 사유를 선택 입력해야 합니다. 퇴근 등록을 누락한 경우 익일 오전 중 정정 신청이 가능하나, 그 이후에는 부서장 승인 절차를 거쳐야 합니다.

### 휴가 신청 입력 항목

휴가 신청은 `업무포털 → 복무관리 → 휴가 신청` 화면에서 진행합니다.

신청 시 입력해야 하는 항목은 다음과 같습니다.

- 휴가 종류 선택(드롭다운)
- 시작일과 종료일
- 사유(간단 서술)
- 결재선 지정

`결재선 지정` 팝업에서는 기본으로 직속 부서장이 자동 지정되며, 필요 시 `[결재자 변경]` 버튼으로 다른 승인자를 검색해 지정할 수 있습니다. 입력을 마치면 `[상신]` 버튼을 눌러 제출하며, 제출 전에는 `[임시저장]`으로 잠시 보관할 수 있습니다.

### 유연근무 신청

시차출퇴근제나 재택근무 등 유연근무는 `업무포털 → 복무관리 → 유연근무 신청` 화면에서 별도로 신청합니다. 적용 희망 기간과 근무 형태를 선택한 뒤 결재선을 지정하는 흐름은 휴가 신청과 동일하나, 부서장 승인 외에 인사부서 확인 단계가 하나 더 추가됩니다. 다만 반나절 이하의 짧은 시차 조정은 결재 없이 사전 통보만으로 처리되는 경우도 있으니 부서 안내를 확인하십시오.

### 신청 취소와 회수 방법

결재가 완료되기 전이라면 `업무포털 → 복무관리 → 신청내역 조회`에서 해당 건을 선택해 `[회수]` 버튼으로 되돌릴 수 있습니다. 이미 결재가 완료된 건은 회수가 불가능하며, 이 경우 `[취소신청]` 버튼을 눌러 별도의 취소 결재를 새로 상신해야 합니다. 회수와 취소는 서로 다른 절차이므로 화면에 표시된 문서 상태(대기/완료)를 먼저 확인하십시오.

# 전자결재

### 기안 작성 화면

전자결재 문서는 `업무포털 → 전자결재 → 기안작성`에서 시작합니다. 문서 양식을 먼저 선택한 뒤 제목, 본문, 시행일자를 입력하고, 필요한 경우 `첨부파일` 탭에서 관련 파일을 추가합니다. 첨부는 1건당 20MB, 총합 100MB를 넘길 수 없으며 초과 시 업로드 버튼이 비활성화됩니다.

### 결재선 지정과 병렬·순차 구분

`결재선 지정` 팝업에서 결재자를 순서대로 추가하면 기본값은 순차 결재로, 앞 단계 승인이 끝나야 다음 결재자에게 문서가 넘어갑니다. 여러 부서의 동시 검토가 필요한 경우 `[병렬 결재로 전환]` 옵션을 선택하면 지정된 결재자들에게 동시에 문서가 전달되며, 전원 승인되어야 다음 단계로 진행됩니다.

### 반려와 재상신

결재자가 문서를 반려하면 기안자에게 알림이 오며, `업무포털 → 전자결재 → 반려함`에서 반려 사유를 확인할 수 있습니다. 내용을 수정한 뒤에는 `[재상신]` 버튼을 눌러 동일 문서 번호로 다시 제출합니다. 반려된 문서를 그대로 두고 신규 기안으로 새로 작성하면 이전 이력과 연결되지 않으므로 반드시 재상신 기능을 사용하십시오.

### 대결 지정과 문서 검색

결재자가 휴가 등으로 부재중일 때는 `업무포털 → 전자결재 → 대결관리`에서 미리 대결자를 지정해 둘 수 있습니다. 대결과 전결은 다른 개념으로, 대결은 결재자 부재 시 임시로 승인 권한을 위임받는 것이고 전결은 규정상 최종 결재권이 애초에 하위 직급에 있는 경우를 뜻하니 문서 양식 선택 단계에서 혼동하지 않도록 주의하십시오. 지나간 문서는 `업무포털 → 전자결재 → 문서함 → 통합검색`에서 기안일, 제목, 기안자로 조회 가능합니다.

# 출장·여비 신청

### 출장 신청 입력 항목

출장은 `업무포털 → 출장여비 → 출장 신청` 화면에서 신청합니다. 출장 목적, 출장지, 기간, 교통수단을 입력하고 결재선을 지정한 뒤 상신하며, 출장 전 승인이 완료되어야 법인카드 한도가 자동 조정됩니다.

### 복명서 첨부

출장을 다녀온 뒤에는 `업무포털 → 출장여비 → 복명서 등록` 화면에서 출장 결과를 요약해 입력하고, 관련 자료가 있으면 `첨부파일` 탭에 추가합니다. 복명서를 등록하지 않으면 다음 출장 신청 화면에서 경고 문구가 표시되며, 신규 신청이 제한될 수 있습니다.

### 여비 정산 화면

여비 정산은 `업무포털 → 출장여비 → 여비 정산 신청`에서 진행하며, 교통비·숙박비 등 항목별로 실제 지출액을 입력하고 영수증 이미지를 첨부합니다. 정산 항목은 출장 신청 시 입력한 일정과 자동으로 연동되므로, 일정이 변경된 경우 정산 화면에서 직접 수정한 뒤 진행해야 합니다.

### 반려 시 수정 방법

여비 정산이 반려되면 사유가 알림함에 표시되며, `[수정 후 재상신]` 버튼을 눌러 해당 항목만 고쳐 다시 제출할 수 있습니다. 영수증 누락으로 인한 반려가 가장 흔하므로, 재상신 전 `첨부파일` 탭에서 파일이 정상 표시되는지 확인하십시오.

# 시설예약

### 예약 화면 이용법

회의실이나 강의실 예약은 `업무포털 → 시설예약 → 시설 예약`에서 진행합니다. 원하는 건물과 날짜를 선택하면 시간대별 예약 현황이 표에 표시되며, 빈 시간대를 클릭하면 예약 신청 팝업이 뜹니다.

| 표시 색상 | 의미 |
| --- | --- |
| 흰색 | 예약 가능 |
| 회색 | 예약 완료 |
| 빗금 | 점검 중(예약 불가) |

### 반복 예약 설정

정기 회의처럼 같은 시간대를 여러 주에 걸쳐 사용하는 경우 `[반복 예약]` 옵션을 켜고 반복 주기와 종료일을 지정하면 됩니다. 반복 예약 중 특정 회차만 취소하려면 예약 목록에서 해당 회차를 개별 선택해 `[해당 회차만 취소]`를 눌러야 하며, `[전체 취소]`를 누르면 이후 모든 회차가 함께 취소되니 주의하십시오.

### 예약 취소와 이용 내역 조회

취소는 `업무포털 → 시설예약 → 내 예약 조회`에서 해당 건을 선택해 `[예약취소]` 버튼으로 처리합니다. 이용이 끝난 예약 내역은 같은 화면의 `이용완료` 탭에서 확인할 수 있으며, 다만 시작 시각 이후에는 취소 버튼이 비활성화되고 대신 `[사유 등록]`으로 불참 사유만 남길 수 있습니다.

# 자주 발생하는 오류와 조치

### 첨부파일 업로드 실패

첨부파일이 올라가지 않을 때는 대부분 용량 초과이거나 파일명에 특수문자가 포함된 경우입니다. 파일명을 한글·영문·숫자와 하이픈으로만 바꾼 뒤 다시 시도하십시오. 그래도 실패하면 브라우저 캐시 문제일 수 있으므로 새로고침 후 재시도하고, 반복되면 헬프데스크로 문의하십시오.

### 결재선 지정 오류

결재선 팝업에서 결재자를 검색해도 목록에 나타나지 않는 경우, 해당 직원이 인사 발령 처리 중이라 시스템 반영이 지연된 상태일 수 있습니다. 이때는 `[직접입력]` 옵션으로 사번을 입력해 지정하거나, 인사부서에 반영 여부를 확인하십시오.

### 화면 미표시 및 로딩 오류

메뉴 클릭 후 화면이 뜨지 않으면 팝업 차단 설정이 원인인 경우가 많습니다. 브라우저 주소창의 팝업 차단 아이콘에서 `portal.nxtcloud.ac.kr`을 허용으로 변경하십시오. 세션 만료로 인한 자동 로그아웃 이후에도 화면이 하얗게 남아 있을 수 있으니, 이 경우 새로고침 후 재로그인하십시오.

### 문의 창구와 처리 시간

시스템 오류는 `업무포털 → 우측 하단 헬프데스크 아이콘 → 오류 신고`에서 접수하며, 접수 시 오류가 발생한 화면 경로와 스크린샷을 첨부하면 처리가 빨라집니다. 헬프데스크는 접수 후 4시간 이내 1차 답변을 원칙으로 하며, 긴급 장애는 전화 문의도 함께 이용하십시오.

접수 화면에서는 오류 유형을 다음 중에서 선택하도록 되어 있습니다.

- 로그인·인증 오류
- 결재·기안 화면 오류
- 첨부파일·문서 조회 오류
- 기타

유형을 정확히 선택해야 담당 부서로 바로 배정되어 처리 시간이 단축됩니다. 다만 여러 화면에 걸쳐 동시에 발생하는 오류라면 `기타`를 선택한 뒤 본문에 증상을 상세히 기재하십시오.
