# RAG 샌드박스 — AI 어시스턴트(Codex) 안내서

이 폴더는 **코딩 입문자**가 AI 어시스턴트와 함께 고쳐 쓰는 RAG(문서 검색 AI) 실습 앱입니다.
사용자는 코딩 경험이 거의 없습니다. 모든 답변은 한국어로, 전문용어는 풀어서 설명하세요.
수정 후에는 "python app.py로 다시 실행하고 브라우저를 새로고침하세요"라고 안내하세요.

## 파일 지도

| 파일 | 역할 | 수정해도 되나요? |
|---|---|---|
| `config.py` | 제목·프롬프트·청크 크기·모델 설정 | ✅ 가장 먼저 만질 곳 |
| `index.html` | 화면 디자인 (HTML/CSS/JS) | ✅ 자유롭게 |
| `guide.html` | 사용자용 쉬운 설명서 (앱의 /guide에서 열림) | ✅ 자유롭게 |
| `app.py` | 서버코드 — 브라우저 요청 처리 | ⚠️ 요청받은 기능 추가만 |
| `rag.py` | 청크 분할·벡터 검색·벡터디비 관리 | ⚠️ 동작을 설명한 뒤 신중히 |
| `llm.py` | Gemini/Bedrock AI 호출 | ⚠️ 모델 이름 교체 외 수정 자제 |
| `data/` | 검색 대상 문서 (.md/.txt) | ✅ 파일 추가·삭제 |
| `samples/` | 예시 문서 원본 (화면의 [샘플 문서] 버튼이 data/로 복사) | ⚠️ 원본은 보존 |
| `vector_db.json` | 벡터디비 (자동 생성됨) | ❌ 직접 편집 금지 |
| `.env` | Gemini API 키 | ❌ 내용을 코드에 복사 금지 |

## 반드시 지킬 규칙

1. **외부 패키지를 추가하지 마세요.** 이 앱은 파이썬 표준 라이브러리만 씁니다 (EC2의 boto3 제외).
   `pip install`이 필요한 해결책 대신 표준 라이브러리로 해결하세요.
2. **API 키를 코드에 하드코딩하지 마세요.** 키는 `.env` 파일에만 둡니다.
3. **vector_db.json을 직접 수정하지 마세요.** 문제가 있으면 화면의 [DB 초기화] → [DB 만들기] 버튼을 안내하세요.
4. `config.py`의 `CHUNK_SIZE`를 바꾸면 **DB를 다시 만들어야 반영**됩니다 — 바꿀 때마다 함께 알려주세요.
5. 로컬(Gemini)과 EC2(Bedrock)는 임베딩이 달라 **벡터디비를 서로 넘겨 쓸 수 없습니다.**
   환경을 옮기면 DB를 새로 만들어야 합니다.
6. `{context}`와 `{question}` 표시는 프롬프트에서 지우면 앱이 고장납니다.

## 사용자가 자주 요청할 것들

- "제목/색깔/디자인 바꿔줘" → `index.html`의 `:root` 색 변수와 `config.py`의 `APP_TITLE`
- "AI 말투 바꿔줘" → `config.py`의 `PROMPT`
- "검색이 잘 안돼" → `CHUNK_SIZE` 조정(작게) + DB 다시 만들기 + 질문을 구체적으로
- "내 문서 넣고 싶어" → data 폴더에 .md/.txt 넣기 (PDF는 텍스트로 변환 필요) + [DB 만들기]

## 실행

```
python app.py   →   브라우저에서 http://localhost:8501
```
