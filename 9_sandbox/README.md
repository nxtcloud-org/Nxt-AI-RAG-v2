# 9. RAG 실습 앱 — 내 문서로 만드는 검색 AI

Streamlit 없이, 설치할 패키지 없이, **파이썬만 있으면 돌아가는** 초소형 RAG 앱입니다.
AI 에이전트(Codex·Claude 등)와 질의응답하며 구조를 이해하고,
자기 업무 서비스로 발전시켜 나가도록 설계된 실습 앱입니다.

## RAG가 이 폴더 안에 그대로 있습니다

```
질문 ──→ ✂️ 청크 검색 ──→ 🤖 AI 답변
              ↑
📁 data/  ──→  ✂️ 청크 분할  ──→  🗄️ vector_db.json
(파일 저장폴더)    (rag.py)           (벡터디비)
```

| 개념 | 실체 | 설명 |
|---|---|---|
| 📁 파일 저장폴더 | `data/` | 검색시키고 싶은 문서(.md/.txt)를 넣는 곳 |
| 🖥️ 서버코드 | `app.py` | 브라우저의 요청을 받아 처리하는 프로그램 |
| 🗄️ 벡터디비 | `vector_db.json` | 청크+벡터가 든 JSON 파일 하나. 열어서 구경해 보세요 |
| 🧠 AI 호출 | `llm.py` | 로컬=Gemini, EC2=Bedrock 자동 선택 |
| 🔧 설정 | `config.py` | 제목·프롬프트·청크 크기 — 가장 먼저 만질 곳 |
| 🎨 화면 | `index.html` | 디자인 전부 — 자유롭게 바꿀 곳 |
| 📖 설명서 | `guide.html` | 비개발자용 쉬운 설명서 (앱 우측 상단 또는 `/guide`) |

## 실행 방법

### 내 컴퓨터에서 (Gemini 무료 키 사용)

1. [aistudio.google.com/apikey](https://aistudio.google.com/apikey)에서 무료 API 키 발급
2. `.env.example` 파일을 복사해 `.env`로 저장하고 키 붙여넣기
3. 실행:
   ```bash
   python app.py
   ```
4. 브라우저에서 `http://localhost:8501` 접속

### EC2에서 (Bedrock 사용 — 키 파일 불필요)

```bash
python3 app.py
```
브라우저에서 `http://<EC2 퍼블릭IP>:8501` 접속 (보안그룹 8501 필요)

## 사용 순서

1. **문서 넣기** — 화면에서 .md/.txt 업로드, 또는 [🧪 샘플 문서로 바로 해보기] 버튼 클릭
2. **DB 만들기** — 문서를 청크로 쪼개고 벡터로 바꿔 vector_db.json에 저장
3. **질문하기** — 비슷한 청크를 찾아 AI가 근거와 함께 답변

## 이렇게 고쳐 보세요 (Codex에게 부탁해도 좋습니다)

- "제목을 ○○과 문서봇으로 바꿔줘" / "화면을 다크모드로 바꿔줘"
- "AI가 존댓말 공문 말투로 답하게 해줘" (→ config.py의 PROMPT)
- "CHUNK_SIZE를 300으로 줄이면 검색이 어떻게 달라져?" (바꾸면 DB 다시 만들기!)
- "답변 아래에 근거 청크 대신 출처 파일명만 보이게 해줘"

## 주의

- 로컬(Gemini)과 EC2(Bedrock)는 임베딩이 달라 **vector_db.json을 서로 넘겨 쓸 수 없습니다.**
  환경을 옮기면 [DB 초기화] → [DB 만들기]를 다시 하세요.
- 업로드 가능: md·txt·csv·hwpx·pptx·docx (한글·PPT·워드·CSV는 자동으로 텍스트 변환 저장).
  구버전 hwp·ppt·doc는 새 형식으로 다시 저장 필요, PDF는 텍스트로 변환해서 넣어 주세요.
- `.env`의 API 키는 비밀번호입니다. 공유·업로드 금지.
