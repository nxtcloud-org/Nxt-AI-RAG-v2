🚀 지금은 최소 구성 — 실무에서는 이렇게 확장됩니다

      

        이 앱의 모든 부품은 실제 AI 서비스의 축소판입니다.
        에이전트에게 부탁하면 실무용 부품으로 교체할 수 있습니다.

      

        
이 실습 앱에서는실무·운영 환경에서는

        
📁 data/ 폴더에 문서 몇 개
            S3, 구글 드라이브, 사내 문서시스템과 연동해 자동 수집

        
📄 ZIP 열어 글자만 줍는 변환 (extract.py)
            AWS Textract, Unstructured, LangChain Document Loader

        
✂️ 글자 수로 자르는 청크 (rag.py)
            LangChain 스플리터, Bedrock KB의 의미 단위 자동 청킹

        
🗄️ vector_db.json 파일 하나
            오픈소스 Chroma·FAISS → 운영급 OpenSearch·pgvector·Pinecone → 완전관리형 Bedrock Knowledge Base

        
🖥️ 표준 라이브러리 서버 (app.py)
            FastAPI·Flask, 또는 서버리스 Lambda + API Gateway

        
🎨 HTML 한 장 (index.html)
            React 등 웹 프레임워크, 사내 포털·메신저 봇에 탑재

        
🤖 AI 직접 호출 (llm.py)
            모니터링을 갖춘 LLM 게이트웨이, RAG 프레임워크

        
🛡️ 키워드 차단·마스킹 (guardrail.py)
            AWS Bedrock Guardrails — 주제 차단, PII 마스킹, 근거 검증

      

      
💬 에이전트에게 이렇게 부탁해 보세요 —
        "벡터디비를 Chroma로 바꿔줘", "서버를 FastAPI로 바꿔줘".
        이때부터는 pip install(외부 패키지)이 필요해집니다.
        그 문턱을 넘는 순간이 실제 개발의 시작입니다.
        (수업에서 만난 Chroma와 Bedrock Knowledge Base가 바로 이 벡터디비의 실무 버전입니다)
